# Original Text

```ad-quote
(3) … For the same thing both can be thought of and can be. [Alternative
translations: “For thinking and being are the same”; “The same thing is for
thinking and for being.”]
```

# Analysis

## Base Level

Properly using thinking (to *Noein*) means that the object *must* exist. Backs up a “Sense of Is” referring to an **Existential Sense (There Exists)**.
