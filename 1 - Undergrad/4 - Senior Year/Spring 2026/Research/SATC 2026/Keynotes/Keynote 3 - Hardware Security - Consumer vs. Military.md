# Introduction

Consumer electronics, military systems, IoT devices, etc
- A network fo devices that connect and exchange data
- Data is collected and transmitted without human interaction
- Requires sensors, processor, and newtwork connections
- Data is sent around and processes

```ad-warning
- Allows for remote control of actions; possibly even autonomous control
- Hardware, firmware, and software, can be exploited
```

## The Problem is Huge

- Supply chain assurance affects everything
- Contract Manufactures try to cut costs wherever possible
- Gray-market, substandard, or counterfeit components are prevalent → they’re **CHEAP**
- IoT gadgets get into data or the home networks
- Inexpensive → Market penetration → lots of sales → possible exploitation
- Hardware can’t directly be patched

```ad-warning
Hardware across different components can be completely different. Sometimes on the same devices!
```

# Defense vs. Consumer Electronics


| Military Applications           | Consumer Applications                      |
| ------------------------------- | ------------------------------------------ |
| Esoteric and novel solutions    | Easy implementation, reproduceable         |
| Revolution changes, large leaps | Incremental improvements                   |
| Long lasting                    | Last until the next thing                  |
| US manufacturing and control    | Use of international contract manufactures |
| ITAR, EAR, DFARS, DMEA          | Self-imposed regulation                    |
| Security is mandated            | Security is nice to have                   |
| Large budgets                   | Narrow margins                             |
| A few thousand units            | MILLIONS of units                          |
