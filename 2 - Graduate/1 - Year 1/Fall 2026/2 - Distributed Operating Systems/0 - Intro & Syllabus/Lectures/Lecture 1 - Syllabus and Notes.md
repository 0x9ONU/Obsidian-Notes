## Course Overview

- Focuses on philosophy and theory
- Be aware of vector math
- Before starting any topic, orthodox OS topics will be laid out to be refreshed before the lectures
- Focusing mainly on real-time scheduling algorithms
	- Learn the difference between real-time and pseudo real-time
	- Earliest-Deadline-First (EDF) scheduling

**Five main topics**:
1. Distributed operating systems
2. RTOS
3. Embedded systems
4. System algorithms
5. Multi-process programming

```ad-danger
Be aware of your resources online via free tutorials might not always be 100% right. Make sure to double check your work and make sure you **understand** the problem rather than copy-paste
```

```ad-important
Global distributed systems and global clocks are super important. We must keep things synchronized to work. i.e. Amazon systems
```
